# 🎉 Nirvana Tech Fest Landing Page

A responsive and visually engaging landing page developed for **Nirvana Tech Fest**, the flagship technical event of Graphic Era Hill University. This project was built during **Webathon 3.0**, where our team secured **1st Place**.

## 🚀 Overview

The website was designed to provide visitors with essential information about the event, including its highlights, schedule, competitions, and registration details. The primary focus was to create a modern, responsive, and user-friendly interface that delivers an engaging experience across all devices.

## ✨ Features

- 🎨 Modern and responsive landing page
- 📱 Mobile-first and fully responsive design
- 🗓️ Event information and highlights
- 🎯 Sections for competitions and activities
- 🚀 Smooth navigation and interactive UI
- ⚡ Optimized for performance and accessibility

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 🏆 Achievement

🥇 **Winner of Webathon 3.0**

Developed this project as part of a team during a 4-hour Webathon competition, where we secured **1st Place** by building a responsive and visually appealing landing page for the event.




## 📌 Purpose

This project demonstrates responsive web design, front-end development skills, and the ability to build a complete landing page within a limited time during a competitive hackathon environment.
